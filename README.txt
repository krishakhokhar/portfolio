Krisha Khokhar — Portfolio Website
====================================

How to view:
- Just double-click "index.html" — it opens in any browser, no server or install needed.
- Everything (styling, fonts loading, animations) is self-contained in this one file, aside from
  two Google Fonts (Space Mono, JetBrains Mono, Manrope) loaded online. It still looks fine offline,
  just with a fallback system font.

How to publish it for free (pick one):
- GitHub Pages: create a repo, upload index.html, enable Pages in repo Settings -> Pages.
- Vercel / Netlify: drag-and-drop this folder onto vercel.com/new or app.netlify.com/drop.

How to customize:
- All content (name, projects, skills, links) lives directly in the HTML in index.html — search for
  the text you want to change and edit it in place.
- Colors are defined once near the top of the <style> block under ":root { ... }" — change the hex
  values there to re-theme the whole site.
- Sections are in order: hero, about, skills, work (projects), journey (timeline), certifications,
  contact — each wrapped in a <section id="..."> tag matching the nav links.
